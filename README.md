# Text to Speech Converter (Python)

A simple Python application that converts user text input into spoken audio using the `pyttsx3` library.

## Pyttsx3 Core Commands Overview

| Command | Description | Function |
| :--- | :--- | :--- |
| `pyttsx3.init()` | Engine Start | Initializes the TTS engine (Runs once) |
| `getProperty()` | Check Settings | Fetches current speed, volume, or voice info |
| `setProperty()` | Change Settings | Adjusts speed rate, volume, or male/female voice |
